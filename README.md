# Sales Dashboard

An interactive **Power BI** dashboard for analyzing business performance.  
It visualizes **sales, profit, units sold, and discounts** across countries with country-wise and product-wise insights.

## 🚀 How to Open the Dashboard

1. Download the file `dashboardsampledata.pbit`
2. Open it using **Power BI Desktop**
3. When prompted, load the data source

---

## 🔍 Key Features

- Sales, Profit, Units Sold & Discount analysis
- Country-wise performance insights
- Product-wise breakdown
- Interactive visuals and filters

---

## 🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel (for data cleaning)
